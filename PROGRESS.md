# Scene2Prompt — Progress

> **Provider:** switched from Anthropic (`@anthropic-ai/sdk`) to **Google Gemini** (`@google/genai`, `gemini-2.5-flash`); key is now `GEMINI_API_KEY`. Prompts, JSON contracts, and UI unchanged. (Phase 1 line below reflects the original Anthropic scaffold.)
>
> **Two modes (added post-Phase 7):** top toggle — **Free · my own chat** (default, no key: extract frames → download → copy a paste-ready instruction for claude.ai via `lib/manualInstructions.ts` + `components/ManualMode.tsx`) and **Automatic · API key** (the existing 3-step Gemini flow). `PromptOptionsForm` gained optional `hideTier`/`hideGenerate` props.
>
> **Frames:** video sampling raised from 8 → **20** frames (`lib/extractFrames.ts`). Free mode now downloads **all frames as one .zip** (`jszip`) instead of one-by-one.
>
> **Auto captions (new tool tab):** top-level **Video prompt** / **Auto captions** tabs. Captions run fully in-browser, no key: `lib/extractAudio.ts` (decode → 16 kHz mono PCM) → `lib/whisper.worker.ts` (Whisper `Xenova/whisper-base.en` via `@huggingface/transformers`, `return_timestamps: "word"`) → `components/CaptionPlayer.tsx` (video + live karaoke overlay, highlight color / words-per-line / text-size controls) → `components/CaptionStudio.tsx` orchestrates (file pick, model-download progress, transcription). Word timing is approximate. **Export added:** "Download video with captions" burns captions into a **.webm** via MediaRecorder (offscreen canvas frames drawn by `lib/captions.ts` `drawCaptionFrame` + audio routed through Web Audio), recorded in real time. **Styling added:** font (Anton/Bangers/Montserrat/Poppins/System via `next/font`), free position (`posX`/`posY` 0–100% sliders — left↔right, up↕down), word gap (`gapEm`), and animation (none/pop/bounce — CSS keyframes in `globals.css` for preview, `wordAnim` per-frame math for canvas export) — all applied in both preview and export.
